# Annahme-Seite für Angebote

Statische Seite (reines HTML, CSS und JavaScript, ohne Build), auf der Kunden ein Angebot online ansehen und annehmen oder ablehnen können.

- Der Link zum Angebot enthält hinter dem „#“ einen geheimen Code. Er wird nie an den Server dieser Seite geschickt.
- In diesem Repository steht nichts Geheimes: keine Zugangsdaten und keine Kundendaten.
- Die Dateien werden aus dem Projekt „PZ Rechnung“ (`apps/angebot-seite`) hierher kopiert – bitte nicht von Hand ändern.
